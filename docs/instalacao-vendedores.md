# Como instalar a Esteira do Repasse

Guia de uma página para os vendedores.

## 1. Baixar

Abra este endereço no navegador e baixe o arquivo **EsteiraRepasse-Setup-…exe**:

**https://github.com/rrenatotc/esteiraRepasse/releases/latest**

## 2. Instalar

1. Dê dois cliques no arquivo baixado.
2. O Windows pode mostrar a tela azul **"O Windows protegeu o computador"**. É normal na primeira vez, porque o app ainda não tem assinatura digital.
   - Clique em **Mais informações**.
   - Depois clique em **Executar assim mesmo**.
3. A instalação é automática e não pede senha de administrador. Ao terminar, o app abre sozinho e cria um atalho na área de trabalho.

## 3. Entrar

1. Na tela inicial, clique em **Entrar** no canto superior direito.
2. Use o e-mail e a senha que o Renato passou para você.
3. No primeiro acesso, vá em **Ajustes → Trocar senha** e escolha uma senha sua (no mínimo 8 caracteres).

O app lembra o seu login neste computador.

## 4. No dia a dia

- **Registrar venda:** placa → CPF ou CNPJ do lojista → valor e loja da proposta → revisar e enviar.
- **Minhas vendas:** acompanhe o status. Se uma venda voltar com pendência, ela aparece no topo com o motivo; clique em **Corrigir e reenviar**.
- **Fechar a janela não fecha o app:** ele fica perto do relógio do Windows (bandeja) para os avisos continuarem chegando. Para sair de verdade, clique com o botão direito no ícone da bandeja → **Sair**.
- **Atualizações chegam sozinhas.** Quando aparecer a faixa **"Reiniciar para atualizar"**, clique nela quando puder.

Problemas? Fale com o Renato (Repasse).
